# 法定节假日与调休数据
#
# 格式：日期|类型
#   类型 holiday = 法定休假日（放假）
#   类型 workday = 调休上班日（本该休息但要上班的周末）
# 以 # 开头的是注释，空行忽略。
#
# ⚠️ 当前文件没有填入任何数据。
#
# 没有数据不代表工具不能用：
#   - 自然日计算（add）仍然可用，只是无法判断届满日要不要顺延，会明确标注
#   - 工作日计算（workdays）会直接拒绝执行 —— 宁可不算，也不能算错
#
# 数据来源请填写国务院办公厅发布的年度放假安排通知，
# 每年更新一次。填完后用 `node scripts/deadline.js coverage` 确认覆盖年份。
#
# 示例（请替换为真实公告数据）：
# 2026-01-01|holiday
# 2026-01-02|holiday
# 2026-01-04|workday

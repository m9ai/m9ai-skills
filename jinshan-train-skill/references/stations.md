# 金山铁路沿线站点

线路顺序（上海南 → 金山卫方向）：**上海南 → 莘庄 → 春申 → 新桥 → 车墩 → 叶榭 → 亭林 → 金山园区 → 金山卫**

反向（往上海南方向）顺序完全颠倒。上海南与金山卫为两端终点站。

---

- 电话：021-51245499

  - 北广场：729路、747路、763路、1252路、虹桥枢纽1路、301路夜宵线、303路夜宵线

# 金山铁路常见问题

## 乘车与购票

**如何买票、需要身份证吗？**
金山铁路属于市域铁路，支持直接刷上海公共交通卡、微信/支付宝乘车码、Metro 大都会等进站，无需提前购票，也无需身份证。

**微信、支付宝等乘车码能用吗？**
可以。支持微信乘车码、支付宝乘车码、上海公共交通卡、Metro 大都会 APP、随申码等多种支付方式，直接扫码或刷卡过闸即可。

**金山铁路能在 12306 上买票吗？**
不能。金山铁路是市域铁路，不属于国铁网络，不在 12306 售票。直接刷交通卡或手机乘车码即可进站乘车。

**可以使用全国交通联合卡吗？**
上海公共交通卡（含交通联合卡）一般可使用，但部分异地联合卡可能存在兼容问题，建议优先使用微信/支付宝乘车码。

**有儿童票吗？多大需要买票？**
每位成人可免费携带一名身高 1.3 米以下的儿童，超过一名或身高超过 1.3 米需购买全价票。

## 班次与时刻

**首末班车时间是几点？**
上海南站往金山卫方向首班车约 05:20、末班车约 22:00；金山卫往上海南方向首班车约 05:30、末班车约 21:55。具体以当日时刻表为准，节假日可能调整。

**上海南到金山卫全程多长时间？**
直达车约 32-34 分钟；大站停约 40-50 分钟；站站停约 50-60 分钟。

**如何区分直达车、大站停和站站停？**
- 直达车（车次 **S1xxx**）：仅停靠起终点站
- 大站停（车次 **S11xx**）：停靠主要大站
- 站站停（车次 **S12xx / S16xx**）：停靠大部分或全部站点

**每日开行和日常开行有什么区别？**
「每日开行」表示该班次每天都运行；「日常开行」通常指工作日运行，周末和节假日可能调整。请以当日实际运行方案为准。

## 站内与乘车

**到了上海南站怎么乘坐金山铁路？**
金山铁路候车室位于上海南站南广场附近，请根据站内指示牌前往，建议提前 15-20 分钟到达。

**列车有固定座位吗？**
不指定座位，先到先得。高峰期可能需站立乘车，建议避开早晚高峰或提前候车。

**自行车或折叠车能带上车吗？**
除折叠电动自行车外，普通自行车和折叠自行车在包装完好、长宽高之和不超过 160cm、重量不超过 20kg 的情况下可携带。详情请咨询车站工作人员。

**乘车时物品丢失怎么办？**
请立即联系车站工作人员或拨打客服热线 021-12306，也可通过「上海铁路12306」微信公众号登记遗失物品。

## 禁止与限制携带物品

### 禁止携带

| 类别 | 说明 |
|---|---|
| 枪支子弹类 | 各类枪支、弹药及主要零部件，含仿真枪、道具枪 |
| 爆炸物品类 | 炸药、雷管、导火索、烟花、爆竹、礼花弹 |
| 管制器具类 | 匕首、三棱刀、弹簧刀等管制刀具；弩、催泪器 |
| 易燃易爆物品 | 汽油、煤油、酒精、油漆、固体酒精、发泡剂 |
| 毒害品/腐蚀品 | 剧毒化学品、农药、硫酸、盐酸、蓄电池 |
| 放射性/感染性物品 | 放射性同位素、传染病病原体 |

### 限制携带

| 类别 | 说明 |
|---|---|
| 散装白酒 | 累计不超过 3000ml 且需包装完好 |
| 刀具/利器 | 非管制刀具限带 2 把，需包装完好，刀尖角度与长度有限制 |
| 宠物/活体动物 | 除导盲犬外，宠物、活禽等禁止携带进站 |
| 重量体积 | 儿童 10kg、成人 20kg，长宽高之和不超过 160cm |

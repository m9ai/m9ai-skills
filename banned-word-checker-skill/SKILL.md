# 违禁词扫描

扫描文案是否命中平台违禁词。归一化后再匹配，所以「微 信」「微-信」「VX」「薇信」
这类常见规避写法也躲不掉。

纯本地运行，不联网、不上传——**要检测的文案不用发给任何第三方**。

## 何时使用

- 发布前自查（"这段文案能不能发"、"帮我查一下有没有违禁词"）
- 批量检查一批标题或详情文案
- 拿到别人给的文案，想确认有没有埋雷
- 维护自己的违禁词表后批量过一遍历史内容

## 硬性规则

1. **命中不等于违规。** 脚本只看字形，不看语境。「国家级」出现在
   "国家级非遗" 里是合规的，出现在广告里才有风险。**必须把命中片段连同上下文一起给人判断**，
   不要直接下"违规"结论。
2. **语义变体脚本识别不了。** 「加我微信」换成「有意私戳」这种换个说法的规避，
   脚本无能为力——这部分**必须你来补判**，并在结论里说明"已过字形检查，语义层面需人工确认"。
3. **内置词表只是起点。** `references/banned-words.txt` 收录的是通用高频词，
   各平台规则不同且频繁变化。**正式使用前应换成或补充自己的词表**（`--words`）。
4. **不要编造平台规则。** 脚本没给的判定不要说；不确定的一律回复"需按目标平台最新公告确认"。
5. **不要替用户改文案后宣称"已合规"。** 可以给修改建议，但合规性由发布方负责。

## 执行方式

在**技能根目录**下用 Bash 执行，`node` 需 16 及以上版本。

```bash
node scripts/scan.js <文件或目录> [--words=<词表>] [--category=导流,虚假宣传] [--json]
node scripts/scan.js --text="待检测文案" [--words=<词表>] [--json]
node scripts/scan.js --selftest
```

### 参数说明

| 参数 | 说明 |
|---|---|
| `--text=` | 直接检测一段文案，不经过文件 |
| `--words=` | 指定词表，默认 `references/banned-words.txt` |
| `--category=` | 只看指定分类，逗号分隔 |
| `--json` | 输出 JSON，便于二次处理 |

### 词表格式

`references/banned-words.txt`，一行一条：

```
# 分类|主词|别名1|别名2|...
导流|微信|weixin|wx|vx|薇信|威信|徽信|v信
虚假宣传|包过|保过|包通过|不过包退
```

- 分类取值：`导流` / `虚假宣传` / `违规交易` / `医疗夸大`
- **主词也会参与匹配**，不用重复写进别名
- 别名里可以写拼音、字母缩写、同形字——归一化后一并匹配

### 常用示例

```bash
# 直接检测一段文案
node scripts/scan.js --text="加我微-信了解详情，包过不过包退"

# 用自己维护的词表批量扫目录
node scripts/scan.js ./文案 --words=./my-words.txt

# 只看导流类
node scripts/scan.js ./文案 --category=导流
```

## 输出解读

```
文案.txt
  L  1  [导流] 微信  命中「微-信」
         本产品国家级别认证，加我微-信了解，vx: abc123
  L  1  [导流] 微信  命中「vx」
         本产品国家级别认证，加我微-信了解，vx: abc123

检查了 24 个词，共命中 6 处
```

- `命中「…」` 是**原文片段**，不是归一化后的形式，便于人工核对
- 每条都带上下文行，判断是否误报要看上下文
- 退出码：命中为 1，未命中为 0

## 已能识别的规避写法

| 手法 | 例子 | 能否命中 |
|---|---|---|
| 插入空格 | `微 信` | ✓ |
| 插入符号 | `微-信`、`微·信` | ✓ |
| 全角/半角 | `ＷＸ`、`ｗｘ` | ✓ |
| 大小写 | `VX`、`vx` | ✓ |
| 零宽字符 | `微​信` | ✓ |
| 跨行拆分 | `微\n信` | ✓ |
| 同形字/谐音 | `薇信`、`威信` | ✓（需在词表别名里列出） |
| 拼音/缩写 | `weixin`、`wx` | ✓（需在词表别名里列出） |
| **换个说法** | 「加我微信」→「有意私戳」 | ✗ **脚本做不到，需人工** |

## 已知取舍

| 情形 | 处理 |
|---|---|
| 别名互相包含（如「包过」与「不过包退」） | 同一位置只报一次，不重复计数 |
| 词表没有的谐音 | 不识别，需补充到词表别名 |
| 扫描目录 | 只扫 `.txt` `.md` `.csv` `.json` `.html` |
| 大类广告法极限词 | 专项检查见 `ad-law-risk-checker-skill`，本表只含平台侧常见的几条 |

## 回答建议

- 先给结论："检查了 N 个词，命中 M 处"，再按分类列出命中片段与上下文。
- **逐条说明是否可能误报**，尤其是正常语境下也会出现的词（国家级、第一、根治）。
- 结尾必须补一句："以上为字形层面检查，语义层面的规避说法需人工复核；
  最终以目标平台最新规则为准。"
- 命中多时按分类汇总，不要逐条念。

# 广告法风险词检测

检测文案里的**绝对化用语**与**疗效承诺**词，分三级报告并给出上下文。
纯本地运行，不联网、不上传文案。

## 何时使用

- 商品详情页、广告文案发布前自查（"这段文案有没有极限词"）
- 一批素材批量过一遍（"这批详情页有没有违规词"）
- 接手历史文案做合规排查（"以前写的文案有没有问题"）
- 与 `banned-word-checker` 配合做完整的发布前检查

## 硬性规则

1. **必须执行脚本，不要凭记忆默念词表。** 词表有上百个，人会漏。
2. **只能标记疑似，不能判定违法。** 报告里的「高」表示"这个词风险很高，建议改"，
   **不是**"这违反广告法"。是否违法要看语境、是否指向商品服务、能否证实，
   最终由市场监管部门认定。
3. **未发现不等于合规。** 本工具只查绝对化用语与疗效承诺这两类。
   虚假宣传、数据无依据、贬低同行、专利/荣誉造假等问题**查不出来**。
4. **必须看上下文再决定改不改。** 同一个词在「第一层」和「行业第一」里性质完全不同。
   脚本已豁免最有把握的几种合法语境，其余要人工读。
5. 建议优先处理 high 级：那是实践中几乎必然被认定的。

## 执行方式

在**技能根目录**下用 Bash 执行，`node` 需 16 及以上版本。

```bash
node scripts/adlaw.js check <文件|-> [--allow=词,词] [--min-level=high] [--json]
node scripts/adlaw.js --selftest
```

文件填 `-` 时从 stdin 读取。

### 选项

| 选项 | 说明 |
|---|---|
| `--allow=词,词` | 豁免指定词（确需保留的语境） |
| `--min-level=high` | 只报告该级别及以上（`high`/`medium`/`low`） |
| `--json` | 输出 JSON |

### 分级依据

| 级别 | 含义 | 例 |
|---|---|---|
| `high` | 广告法第九条明文列举，或实践中几乎必然被认定 | 国家级、最高级、最佳、顶级、极致、绝对、第一品牌、行业第一、独一无二、100% |
| `medium` | 常见被处罚但需结合语境 | 第一、唯一、首选、首创、独家、领先、最新、超值 |
| `low` | 疗效与绝对承诺类警惕词（多见于医疗、保健食品） | 特效、速效、根治、无副作用、永久、终身、包治 |

法律依据：《广告法》第九条第（三）项——不得使用「国家级」「最高级」「最佳」等用语。

### 已自动豁免的合法语境

- `最佳食用期` / `最佳赏味期` / `最佳保存期` 等法定或惯用标识
- 序数词与名次：`第一层`、`第一步`、`第一名`、`第三季度`
- 客观数值：`最低气温`、`最高海拔`、`最大载重`、`最大容量`

这几条是最有把握的。**不做更多豁免**——过度豁免会让真正的风险词从报告里消失，比误报更危险。

### 常用示例

```bash
# 检查一份文案
node scripts/adlaw.js check ./详情页.txt

# 只看高风险
node scripts/adlaw.js check ./详情页.txt --min-level=high

# 管道用法
cat ./文案.txt | node scripts/adlaw.js check -

# 豁免某个确实要用的词
node scripts/adlaw.js check ./文案.txt --allow=第一
```

## 输出解读

```
发现 7 处风险词（高 4 / 中 1 / 低 2）

     2:  4  [高] 行业第一   …级材料精心打造。 我们是行业第一的品牌，消费者的首选。 …
     2: 16  [中] 首选     …行业第一的品牌，消费者的首选。 本保健品可根治失眠，…
```

`行:列` 便于定位，上下文前后各取 12 字用于判断语境。
退出码：`0` 无 high 级，`1` 存在 high 级，可用作发布前卡口。

## 已知取舍

| 情形 | 处理 |
|---|---|
| 「第一层」这类序数词 | 自动豁免 |
| 「最佳食用期」 | 自动豁免 |
| 「最受欢迎」等主观表述 | 报 medium，需人工判断 |
| 客观规格参数（最大载重） | 自动豁免 |
| 虚假宣传、数据无依据 | **查不出** |
| 贬低同行、专利造假 | **查不出** |
| 词库未收录的极限词 | **查不出**，词库不完备 |
| 港澳台或海外广告法规 | 不适用，仅依据中国大陆《广告法》 |

## 与 banned-word-checker 的分工

| | 本工具 | `banned-word-checker` |
|---|---|---|
| 管什么 | 广告法绝对化用语、疗效承诺 | 平台违禁词 |
| 依据 | 《广告法》 | 各平台规则 + 企业自有词表 |
| 后果 | 行政处罚风险 | 商品下架、账号处罚 |

发布前建议**两个都跑**：一个管法律风险，一个管平台风险。

## 回答建议

- 先报"发现 N 处（高/中/低 各多少）"，再按级别列出词与上下文。
- **每次都要说明**：这是疑似标记，不是违法认定；最终以监管部门认定为准。
- high 级建议直接改写，medium 级建议结合语境判断，low 级重点看医疗/保健类目。
- 用户问"这样写违法吗"时，明确回答"不能判定，建议咨询法务或属地市场监管部门"。
- 给出改写建议时可用「领先」→「位居前列」、「唯一」→「少有」这类更稳妥的替代表述。
